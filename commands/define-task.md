引导用户结构化描述一个任务，确保背景、目标、要求清晰完整后再开始执行。

模板格式见 docs/task-template.md，必须严格遵循。

## 引导流程

### 第一步：收集背景

问用户：**这个任务要解决什么问题？当前遇到了什么情况？**

用户回答后，帮他整理成简洁的「背景」段落（不超过 3 句话）。

**背景描述准确？（0=不准确需要调整 / 1=准确继续）**

### 第二步：明确目标

问用户：**做完之后你期望看到什么结果？**

将回答提炼为一句可验证的目标。

**目标描述准确？（0=不准确需要调整 / 1=准确继续）**

### 第三步：梳理要求

问用户：**有没有必须遵守的约束？比如技术限制、不能动的东西、质量要求？**

如果用户说"没有"，根据背景和目标主动提出可能的约束供确认。

**约束条件确认？（0=需要调整 / 1=确认继续）**

### 第四步：定义验收标准

根据前三步的信息，主动生成验收标准清单。

**验收标准确认？（0=需要补充 / 1=确认继续）**

### 第五步：输出完整任务

按 docs/task-template.md 的格式，输出完整的结构化任务描述。

**确认并开始执行？（0=需要调整 / 1=确认开始执行）**
