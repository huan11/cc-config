将当前对话中的讨论内容整理并保存为 Markdown 文档。

## 输入参数

用户提供的话题关键词：$ARGUMENTS

如果用户未提供话题关键词，则从对话内容中自动提取一个简洁的话题名（中文，不超过 20 字）。

## 执行步骤

1. **确定文件名**：格式为 `YYYY-MM-DD-HHmm-话题名.md`，日期取当天，`HHmm` 为当前 24 小时制时间（如 `2026-03-06-1430-智能体技术选型.md`）。通过时间戳自然区分同一天的多次讨论并体现先后顺序。
2. **确定保存目录**：
   - 如果当前工作目录是一个项目（有 git 仓库或项目文件），保存到项目根目录的 `docs/discussions/` 下。
   - 否则保存到 `~/Documents/discussions/` 下。
   - 目录不存在时自动创建。
3. **整理内容**：回顾当前对话，提取核心讨论内容，按以下结构组织 Markdown：

```markdown
# [话题名]

> 讨论时间：YYYY-MM-DD HH:mm

## 背景与初心

[讨论的起因、目标、约束条件]

## 讨论要点

### [要点 1 标题]
[要点内容，包含关键结论]

### [要点 2 标题]
[要点内容]

...（按实际讨论内容组织）

## 决策结论

| 决策项 | 选择 | 理由 | 状态 |
|-------|------|------|------|
| ... | ... | ... | 确定/待确认/TODO |

## 待办事项

- [ ] 待办 1
- [ ] 待办 2

## 开放问题

[仍未解决的问题或后续需要深入的方向]
```

4. **写入文件**：使用 Write 工具创建文件。
5. **反馈结果**：告知用户文件保存路径和内容摘要。

## 注意事项

- 内容要忠实于讨论，不要添加讨论中没有的信息
- 结论和决策要准确反映讨论的最终共识
- 语言简洁，去除口语化表达，保留技术精准度
- 如果讨论中有代码片段或架构图，原样保留
