从 Claude 全局命令目录拉取斜杠命令到当前项目，排除 gzh 相关内容。

## 执行流程

### 第一步：扫描差异

对比两个目录的文件：

- **源**：`~/.claude/commands/`（含子目录）
- **目标**：当前项目 `.claude/commands/`

**排除规则**（源目录中以下内容直接跳过，不参与对比）：

- 文件名或路径包含 `gzh` 的所有文件和目录

逐个文件检查，分三类：

| 状态 | 说明 |
|------|------|
| 🆕 新增 | 项目中不存在该文件 |
| 📝 更新 | 两边都有但内容不同（用 diff 确认） |
| ✅ 一致 | 内容完全相同，无需操作 |

把结果列成表格展示给用户。

### 第二步：确认同步

向用户展示将要执行的操作清单，询问：

**以上文件将拉取到项目命令目录，确认？（0=取消 / 1=全部同步 / 或输入要排除的文件名）**

- 用户回复 1 → 全部同步
- 用户回复 0 → 取消
- 用户输入文件名 → 排除指定文件后同步

### 第三步：执行同步

用 `cp` 逐个复制文件（不用 `rsync`，保持可控）：

- 子目录不存在时先 `mkdir -p`
- 每复制一个文件输出一行日志
- 不删除项目目录中多出的文件（只增不减，避免误删项目专属命令）

### 第四步：输出结果

```
拉取完成：新增 X 个，更新 Y 个，跳过 Z 个
```

## 守护栏

- 只同步 `.md` 文件，忽略其他格式
- 只做单向同步（全局 → 项目），绝不反向覆盖全局文件
- 不删除项目目录中全局没有的文件
- 排除所有 gzh 相关文件和目录（包括 `gzh/`、`gzh-v1-backup/` 及任何文件名含 `gzh` 的文件）
- 同步前必须展示差异并获得用户确认，禁止静默覆盖
