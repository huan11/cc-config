将当前项目的斜杠命令同步到 Claude 全局命令目录（`~/.claude/commands/`）。

## 执行流程

### 第一步：扫描差异

对比两个目录的文件：

- **源**：当前项目 `.claude/commands/`（含子目录）
- **目标**：`~/.claude/commands/`

逐个文件检查，分三类：

| 状态 | 说明 |
|------|------|
| 🆕 新增 | 目标不存在该文件 |
| 📝 更新 | 两边都有但内容不同（用 diff 确认） |
| ✅ 一致 | 内容完全相同，无需操作 |

把结果列成表格展示给用户。

### 第二步：确认同步

向用户展示将要执行的操作清单，询问：

**以上文件将同步到全局命令目录，确认？（0=取消 / 1=全部同步 / 或输入要排除的文件名）**

- 用户回复 1 → 全部同步
- 用户回复 0 → 取消
- 用户输入文件名 → 排除指定文件后同步

### 第三步：执行同步

用 `cp` 逐个复制文件（不用 `rsync`，保持可控）：

- 子目录不存在时先 `mkdir -p`
- 每复制一个文件输出一行日志
- 不删除目标目录中多出的文件（只增不减，避免误删其他项目同步过去的命令）

### 第四步：输出结果

```
同步完成：新增 X 个，更新 Y 个，跳过 Z 个
```

## 守护栏

- 只同步 `.md` 文件，忽略其他格式
- 只做单向同步（项目 → 全局），绝不反向覆盖项目文件
- 不删除全局目录中项目没有的文件
- `sync-commands.md` 自身也同步（这个命令本身在其他项目也有用）
- 同步前必须展示差异并获得用户确认，禁止静默覆盖
